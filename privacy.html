바나비 개인정보처리방침

시행일: 2026-11-11

1. 이 앱은 무엇인가요

「바나비」는 운영자 본인이 자기 PC에서만 쓰는 개인 비서 프로그램입니다. 일반 이용자에게 제공하지 않습니다. 운영자 본인의 유튜브 채널에 대해 채널 주인으로서 구글 허락(OAuth)을 받아 아래 일만 합니다.

2. 구글에서 받는 권한과 쓰는 곳

  • 유튜브 분석 보기(yt-analytics.readonly): 내 채널 영상의 조회수·시청 시간·시청자층·유입 경로를 하루 보고로 정리
  • 유튜브 보기(youtube.readonly): 내 채널 정보·영상 목록·댓글 읽기
  • 영상 올리기(youtube.upload): 운영자가 승인한 영상·썸네일을 내 채널에 올림
  • 댓글 관리(youtube.force-ssl): 운영자가 승인한 답글을 달고 내 영상 설명을 고침

3. 저장하는 것

  • 구글이 준 갱신 토큰은 운영자 PC의 비공개 폴더 한 곳에만 저장하고 외부로 보내지 않습니다.
  • 채널 숫자·영상 목록·공개 댓글(작성자 이름은 일부 가림)·분석 결과는 운영자 PC에만 저장하고 하루 보고 작성에만 씁니다.
  • 이 정보를 팔거나 다른 사람에게 넘기거나 광고에 쓰지 않습니다.
  • 구글 API로 받은 정보는 Google API Services User Data Policy(제한적 사용 요건 포함)를 따릅니다.

4. 지우는 법

  • 허락 취소: 구글 계정 → 보안 → 「타사 앱 및 서비스」에서 「바나비」 연결을 지우면 바로 끊깁니다.
  • 저장된 자료: 운영자 PC의 해당 폴더를 지우면 모두 사라집니다.

5. 문의

이 앱은 운영자 본인만 씁니다. 문의는 운영자에게 직접 해 주세요.

6. 바뀌면

이 방침이 바뀌면 이 쪽에 시행일과 함께 올립니다.
